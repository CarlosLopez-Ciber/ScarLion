Una **red de computadoras** es un sistema conformado por múltiples **dispositivos interconectados** que intercambian datos entre sí mediante medios físicos (como cables de red) o inalámbricos (como señales Wi-Fi o Bluetooth). Este conjunto de dispositivos, denominados **nodos de red**, puede incluir:

- Computadoras personales y laptops
- Servidores
- Dispositivos móviles (smartphones, tablets)
- Impresoras en red
- Cámaras IP y dispositivos IoT (Internet of Things)

**Objetivo Principal**

El propósito fundamental de una red es **permitir la comunicación eficiente y segura entre dispositivos**, facilitando el **acceso compartido a recursos, servicios y aplicaciones**. Este intercambio puede realizarse a nivel local (LAN) o a través de redes de mayor escala como Internet.
