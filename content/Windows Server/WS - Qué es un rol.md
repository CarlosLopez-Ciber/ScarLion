## El Rol: "El Trabajo del Servidor"

Un **Rol** es la función principal o la identidad del servidor. Cuando instalas un rol, le estás diciendo al servidor: _"A partir de ahora, este es tu oficio en la red"_.

- **Es hacia afuera:** Generalmente, un rol ofrece servicios a otros equipos o usuarios de la red (clientes).
    
- **Define la identidad:** Si instalas el rol de servidor web, el servidor _es_ un servidor web.
    
- **Ejemplos clásicos:**
    
    - **Active Directory Domain Services (AD DS):** El servidor se convierte en un "Policía/Administrador" de identidades.
        
    - **DHCP Server:** El servidor se convierte en el "Repartidor" de direcciones IP.
        
    - **Print Services:** El servidor se convierte en el "Gestor" de impresoras.
