## La Característica: "La Caja de Herramientas"

Una **Característica** (_Feature_) es un programa o función de software que ayuda al servidor a realizar mejor su trabajo o le otorga capacidades técnicas adicionales, pero no define su propósito principal.

- **Es hacia adentro:** Generalmente, las características son herramientas para que el propio servidor o el administrador realicen tareas específicas.
    
- **Es un complemento:** No necesitas que el servidor tenga un "oficio" (rol) para instalarle una herramienta.
    
- **Ejemplos clásicos:**
    
    - **Windows Server Backup:** Una herramienta para que el servidor pueda respaldarse a sí mismo.
        
    - **BitLocker Drive Encryption:** Una capacidad para cifrar los discos del servidor.
        
    - **Telnet Client:** Una herramienta para probar conexiones desde el servidor a otros equipos.
